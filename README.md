# JavaScript Internship Project

## 📌 Overview

This repository contains the work completed during my JavaScript internship.

The project includes six JavaScript assignments created to practice fundamental programming concepts and a final interactive **Product Management Dashboard** built using HTML, CSS, and JavaScript.

The assignments focus on building a strong foundation in JavaScript, while the dashboard brings several of these concepts together into a practical web application.
