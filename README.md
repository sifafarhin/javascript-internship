# JavaScript Internship Project

## 📌 Overview

This repository contains the work completed during my JavaScript internship.

The project includes six JavaScript assignments created to practice fundamental programming concepts and a final interactive **Product Management Dashboard** built using HTML, CSS, and JavaScript.

The assignments focus on building a strong foundation in JavaScript, while the dashboard brings several of these concepts together into a practical web application.

📊 Product Management Dashboard
```
The main project is an interactive Product Management Dashboard built using HTML, CSS, and JavaScript.
The dashboard allows users to manage and explore product inventory through a simple and modern interface.
✨ Features
- 📦 Total product count
- 💰 Total inventory value
- 🏷️ Category count
- 📊 Average product price
- 🔍 Product search
- 🏷️ Category filtering
- ➕ Add new products
- 🗑️ Delete products
- 📱 Responsive layout
- ✨ Hover effects and animations
- 🔄 Dynamic statistics
- 🎨 Modern dashboard UI
🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- JavaScript Arrays and Objects
- Array Methods
- Event Listeners
- Responsive Web Design
- CSS Animations
📂 Dashboard Files
index.html
Contains the structure of the dashboard, including navigation, statistics, product controls, search, filters, forms, and the product list.
style.css
Contains the dashboard design, responsive layout, product cards, buttons, hover effects, transitions, and animations.
script.js
Contains the dashboard functionality, including product management, searching, filtering, adding and deleting products, and updating statistics.
```
